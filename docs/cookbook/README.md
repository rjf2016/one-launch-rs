# GPUI cookbook

GPUI patterns that compiled against the pinned version. A ticket that needs one names the entry under `cookbook` in its `read` field and copies from it. The rule is in `CLAUDE.md` › "GPUI".

## An entry

- One file per pattern, in this folder, named after the pattern.
- It names the pinned GPUI source file the pattern was taken from: package, version and path, as the cargo registry has them.
- It holds a minimal snippet, and names the spike or crate that snippet compiled in.

A pattern others will copy gets an entry. The file is written by a ticket whose `write_scope` names it, one ticket at a time.
