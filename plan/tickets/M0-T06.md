## Outcome

`oracle/l2/updates/` holds the recorded `updates:status` state sequences and log lines for six feed conditions through the real Electron engine on the loopback test feed: up to date, update available and downloaded, unsigned manifest, wrong key, hash mismatch, network failure.

Each record includes the request the engine made (path and headers that matter) so the Rust updater's feed requests can be compared.

## Out of scope

Running any installer. The install-at-quit step is described in `plan/design/takeover.md` and rehearsed on hosted runners from Milestone 1.

## Traps

- The engine is electron-updater, so this layer runs through Electron, not the headless harness.
- Use only the throwaway keys already in `oracle/fixtures/updates`. Real release keys never enter a session.
- `updates.auto` switched off does not cancel a check already in flight (spec §12.2); record that case.
