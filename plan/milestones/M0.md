# M0 Oracle

**Goal.** A machine-readable reference bundle captured from the Electron app at the pinned commit, and an owner-approved triage table. No Rust is written.

**Where.** The Electron repo, branch `oracle-tooling` cut from the pin. It never merges and never ships. It is pushed to `origin` for safekeeping, with no pull request. Output goes to this repo's `oracle/`. Design: `../design/oracle.md`.

**Rules that apply.** The Electron repo's `CLAUDE.md` in full: fake launchers only, never a real switch, never the real data folder, `npm run check` stays green, no secrets in any output.

## Exit gate

- Every capture repeats identically (vectors twice, replays five times, sidecars repeat-stable).
- The verify script passes: schemas valid, manifest hashes match, secret scan clean, no user paths anywhere.
- Five replay scripts run through real Electron diff to zero against the harness.
- With the recording variable unset, `npm run check` passes and `play-all --fake` leaves no trace file; a packaged build ignores the variable.
