# M2 Core

**Goal.** Everything below the adapters: models, parsers, persistence, vault, logger and the platform layer, real and fake.

`E\` is the Electron repo at the pin. Lanes run in parallel; tickets inside a lane mostly do too.

The milestone opens with one serial interface ticket: module tree, the platform traits, the error enum.

## Exit gate

- All vectors pass.
- The real and the fake registry pass one contract suite.
- The trace shows zero handle opens during process listing.
- A data folder written by Electron round-trips: opens, decrypts, and is still accepted by Electron afterwards.

## The owner's part

- Copy the real data folder somewhere and run `doctor --data-dir=<copy>`. It prints counts only, never contents.
- Run the ported read-only `*-live` tests against the real launchers; they compare hashed digests and commit nothing.
