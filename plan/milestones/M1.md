# M1 Foundation

**Goal.** A repo agents can work in safely, eleven spikes that settle the GPUI and Windows unknowns, a walking skeleton through every layer, and the first takeover rehearsal on CI.

Design: `../design/architecture.md`, `../design/workflow.md`, `../design/gpui-notes.md`, `../design/takeover.md`.

Spikes, all parallel. Each ends in a decision record: pass, or the named fallback.

| # | Spike | Pass | On fail |
| --- | --- | --- | --- |
| S1 | Tray, close-to-tray, hidden start | Starts with no window or taskbar button; tray click shows and focuses; close hides and preserves view state; icon returns after an Explorer restart; `WM_ENDSESSION` observed | Direct `Shell_NotifyIconW` helper window; destroy and recreate the window |
| S2 | Frameless title bar | Drag, double-click maximise, snap flyout on the maximise button, Win+Z, eight resize edges, 960x600 minimum, caption buttons within tolerance of the baseline | Native title bar tinted through DWM |
| S3 | Poster grid | 500 cards, p95 frame under 16 ms, RSS under 250 MB, no decode on the UI thread | Thumbnail cache (triage) |
| S4 | Input and focus | Masked input with reveal, IME, clipboard, undo, Tab order, keyboard-only focus ring, modal trap, Kit root coexisting with our shell | Vendor the Kit input module |
| S5 | Automation and capture | Tree of 500 nodes under 50 ms with bounds and text; click and type without foreground; two static captures identical; correct when occluded and at 150% | `PrintWindow`; Probe registry |
| S6 | Vault and DB | A scratch folder made by Electron via `--data-dir` decrypts fully; a Rust-written secret reads back in Electron; a Rust-created folder is accepted by Electron | Stop: the takeover design changes |
| S7 | Process listing | Paths for all processes including a deny-all DACL; zero opens from our pid in the kernel audit trace; kill opens only its targets | Revisit the API choice |
| S8 | Metrics | Proposed targets: clean release build under 10 min, core test loop under 20 s, exe under 40 MB, first frame under 300 ms, idle RSS under 150 MB | Record and decide |
| S9 | CI window | A GPUI window renders on `windows-latest`, capture non-blank, 5 of 5 runs, required fonts present | Dedicated VM lane for UI parity |
| S10 | Takeover dry run | The contract assertions of `takeover.md` pass on a runner with the public Electron release | Fix the script before Milestone 6 |
| S11 | Text metrics | 20 strings at 11, 12 and 14 px and weights 400, 500, 600 within 1 px per 100 px of Chromium | Define the tolerance policy |

Also decided here, as a decision record: `gpui-pre` exact pin against a pinned git rev of Zed, and whether CSS effects (backdrop blur, inset shadow, scale transforms, colour transitions) have GPUI equivalents.

## Exit gate

- One decision record per spike.
- The skeleton screenshot is produced and compared by CI.
- The guardrails reject a deliberately bad PR of each kind: out-of-scope edit, removed test, protected-path edit, banned crate.
- Cost per merged ticket measured on the first tickets.

## The owner's part

- GPUI go/no-go from the spike sheet.
- Read the one-page architecture (crate graph, traits).
- Install anything that needs elevation.
