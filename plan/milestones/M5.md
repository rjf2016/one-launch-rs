# M5 Screens

**Goal.** Every view and dialog, assembled from the kit, with all 30 scenarios driven through the UI on fake launchers.

`E\` is the Electron repo at the pin. Lanes run in parallel, one per view.

## Tickets

| Lane | Tickets | Ports |
| --- | --- | --- |
| Library | Grid, poster cache and GameCard; toolbar, search, sort and recent row; card menu and manual artwork | `E\src\renderer\src\views\LibraryView.tsx`, `components\{GameCard,CardMenu,ArtworkPanel}.tsx` |
| Accounts | List; detail create; detail edit and SwitchPlanView; SessionPanel; ImportAccountsDialog | `views\{AccountsView,AccountDetailView}.tsx`, `components\{SwitchPlanView,SessionPanel,ImportAccountsDialog}.tsx` |
| Launch | Dialog pick, confirm, preview, blocked; running, finished, attention; LaunchHost banner, instant Play, hide-to-tray | `components\{LaunchDialog,LaunchHost}.tsx`, `lib\phases.ts` |
| Guides | SetupGuide (two tickets), WhatsNew, RecoveryDialog | `components\{SetupGuide,SetupGuideSteps,SetupGuideArt,WhatsNewDialog,RecoveryDialog}.tsx`, `lib\motion.ts` |
| Settings | General and Updates; Launchers; Artwork; Backups; Advanced | `views\SettingsView.tsx`, `components\{UpdatesPanel,LauncherStatusPanel,BackupsPanel}.tsx` |
| Scenarios | X1 to X4: the scenario files ported to the automation driver | `E\scripts\scenarios\*.mjs` |

## Exit gate

- All 30 scenarios pass on fake launchers, driven by input only.
- All 174 states are within tolerance, or have a triage decision.
- The copy inventory matches: every string in `oracle/assets` copy appears verbatim where its state is reachable.

## The owner's part

- The demo build.
- Four real switches through the UI, one per launcher, on a scratch data folder.
